# oblivion-privacy

The privacy policy for **Oblivion**, published so the Google Play listing has a
public URL to point at. Play requires the policy to be reachable without a login,
and Pages cannot serve a private repository on a free plan — hence this separate
public repo.

Live at **https://humbre-tonto.github.io/oblivion-privacy/**

The canonical source is `store/PRIVACY_POLICY.md` in the app repository. If the
policy changes there, update `index.html` here and bump the date in both.
